# 微信小程序-基础知识

**Wechat Mini Program Beginning**

---

## 简介

**微信小程序**是一种运行在微信内部的`轻量级`应用程序，其核心理念是“`触手可及`”和“`用完即走`”。

1. 轻量级：体积小，用户感知不到下载的过程。
2. 触手可及：用户 扫一扫 或 搜一下 即可打开应用，通过下拉能访问使用的小程序。
3. 用完即走：关闭小程序则可离开，无须卸载。

### 开发结构

微信小程序的开发主要分为三个部分：

1. **逻辑层（JS）**：负责处理数据和业务逻辑，使用 JavaScript 编写。
2. **视图层（WXML）**：负责页面布局，使用类似 HTML 的标签语言 WXML 来构建页面结构。
3. **样式层（WXSS）**：负责页面样式，使用类似 CSS 的样式语言 WXSS 来设置页面样式。



## 开始步骤

1. **注册账号**：首先需要在 [微信公众平台](https://mp.weixin.qq.com/) 注册一个微信小程序账号。
   1. 注册的帐号类型，在这里需要 **选择小程序**。
   2. 完善小程序账号信息，填入`小程序信息`和`小程序类目`，获取管理员认证。
2. **下载开发者工具**：下载并安装 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)。
   1. 稳定版的稳定性高，开发中一般推荐使用稳定版本。
   2. 注意，微信开发者工具必须联网使用。
3. **创建项目**：在开发者工具中创建一个新的小程序项目，输入项目名称和AppID，即可开始编写代码。
   1. 使用云服务选项将会使用微信提供的服务器，包括云端资源，包括云函数、云数据库和云存储等(按需收费)。
   2. 不使用云服务则需要开发者自行搭建服务器。
   3. 模板选择可先选不使用模板，也可以选使用 "Js + 基础目标"。

4. **开发者工具设置**：按需对开发者工具进行一些个性化的设置
   1. 顶部栏中选择`试图`-`外观`，则可编辑基本外观设置。
   2. 顶部栏中选择`设置`-`外观设置`，进入外观设置界面，可更改更多设置。
   3. 顶部栏中选择`设置`-`编辑区设置`，可更改行距和字号。

5. **编写代码**：小程序的每个页面由四个文件组成：.js（逻辑）、.wxml（视图）、.wxss（样式）和.json（配置）。开发者可以根据需求编写这些文件来实现功能。



## 目录结构和文件介绍

在将小程序项目创建好以后，我们先来熟悉小程序项目的目录结构，如下图：

<img src="./assets/033-%E5%B0%8F%E7%A8%8B%E5%BA%8F%E7%9B%AE%E5%BD%95.png" style="zoom:80%; border: 1px solid #ccc" />

一个完整的小程序项目分为`主体文件`、`页面文件`两个部分：

1. **主体文件**

   主体文件又称小程序全局文件，顾名思义，全局文件能够作用于整个小程序，影响到小程序的每个页面，且**主体文件必须放到项目的根目录下**，主要由三部分组成：

   |  文件名  |       作用       | 是否必须 |
   | :------: | :--------------: | :------: |
   |  app.js  |  小程序入口文件  |   必须   |
   | app.json | 小程序的全局配置 |   必须   |
   | app.wxss | 小程序的全局样式 |  非必须  |

2. **页面文件**

   页面文件是每个页面所需的文件，小程序页面文件都存放在 pages 目录下，一个页面一个文件夹，每个页面通常由四个文件组成，每个文件只对当前页面有效：

   | 文件名 |   作用   | 是否必须 |
   | :----: | :------: | :------: |
   |  .js   | 页面逻辑 |   必须   |
   | .wxml  | 页面结构 |   必须   |
   | .wxss  | 页面样式 |  非必须  |
   | .json  | 页面配置 |  非必须  |


> 📌 **注意事项**：
>
> 1. 页面文件，wxss、json 文件能够覆盖主体文件中的样式和配置
> 2. 强烈建议：页面文件夹名称和页面文件名称要保持一致

新建小程序文件和文件夹作用清单：

```shell
├─pages	                    ➡ 小程序页面存放目录
│
│  ├─index				   ➡ index 文件夹代表是 index 页面所需的文件
│  │      index.js          ➡ index 页面逻辑
│  │      index.json        ➡ index 页面配置
│  │      index.wxml        ➡ index 页面结构
│  │      index.wxss        ➡ index 页面样式
│  .eslintrc.js              ➡ Eslint 配置文件
│  app.js                    ➡ 小程序入口，即打开小程序首页执行的项目
│  app.json                  ➡ 小程序的全局配置
│  app.wxss                  ➡ 小程序的全局样式
│  project.config.json       ➡ 小程序开发者工具配置
│  project.private.config.json
│  sitemap.json              ➡ 小程序搜索优化
```

## 新建页面

1. **第一种方式：**

   1. 在 pages 目录上 点击右键 `新建文件夹`，输入页面目录的名称，例如：list
   2. 在 list  目录上 点击右键 `点击 page`，输入页面文件的名称，例如：list

   > 📌 **注意事项：**
   >
   > 1. 在输入页面文件名称的时候，不要输入后缀名 
   > 2. 新建页面成功以后，会在 app.json 的 pages 选项中新增页面路径

2. **第二种方式：**

   1. 在 app.json 的 pages 选项中，新增页面路径即可
      在新增页面目录以后，会自动在 pages 目录下生成页面文件



## 调试基础库

小程序调试基础库是指微信开发者工具中可以选择的微信基础库版本。

微信基础库是指小程序的运行环境，给小程序提供了运行所需的各种 API 和工具，以及基础框架和运行逻辑等。

小程序开发者可以在微信开发者工具中选择所需的微信基础库版本，作为运行和调试小程序时的运行环境。

每个小程序有自己所允许使用的基础库最低版本要求，开发者需要选择要兼容的基础库版本，从而确保小程序的功能正常运行。
