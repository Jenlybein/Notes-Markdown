## Dify 简介

**Dify** 是首个将 *Backend-as-a-Service* 理念与 *LLMOps* 深度整合的开源平台，通过*可视化编排*、*企业级工程架构* 和*全链路数据洞察*，助您快速构建生产级生成式AI应用。无论您是开发者、产品经理还是企业决策者，都可以快速搭建生产级的生成式 AI 应用。

- **后端即服务 (Backend-as-a-Service, BaaS)** : 一种云计算服务模式，通过预构建的云端后端组件（如数据库、API 网关、用户认证等），让开发者无需从零搭建基础设施，可快速构建应用前端逻辑。
- **大语言模型运维 (Large Language Model Operations, LLMOps)** ：针对大语言模型的专项运维体系，覆盖模型部署、监控、迭代的全生命周期管理。
- **Dify 的实践路径**
  - 前端：低代码工作台（BaaS 理念）
  - 后端：模型运维中台（LLMOps 能力）
  - 数据流：用户交互 → 效果分析 → 自动优化闭环

**Dify 的特点**：

- Dify 内置了构建 LLM 应用所需的关键技术栈，包括对数百个模型的支持、直观的 Prompt 编排界面、高质量的 RAG 引擎、稳健的 Agent 框架、灵活的流程编排，并同时提供了一套易用的界面和 API。这为开发者节省了许多重复造轮子的时间，使其可以专注在创新和业务需求上。
- LangChain 这类的开发库像是工具箱，而 Dify 好比是一套脚手架。相比之下，Dify 提供了更接近生产需要的完整方案，并且经过了精良的工程设计和软件测试。
- Dify 是开源的，它由一个专业的全职团队和社区共同打造。你可以基于任何模型自部署类似 Assistants API 和 GPTs 的能力，在灵活和安全的基础上，同时保持对数据的完全控制。
- Dify 为所有人提供了云服务，你无需自己部署即可使用 Dify 的完整功能。
