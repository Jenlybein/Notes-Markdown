## GORM 简介

**ORM**（Object-Relational Mapping，对象关系映射）是一种编程技术，用于将面向对象编程语言中的a对象与关系型数据库中的表进行映射。它允许开发者通过操作对象的方式来访问和操作数据库，而无需直接编写复杂的 SQL 语句。

类比理解：想象数据库是一本 Excel 表格，ORM 的作用就是自动将表格的每一行数据转换成结构体变量，开发者只需操作变量，ORM 会帮你同步到表格中。

**GORM** 是 Go 语言的 ORM 库，能将数据库表与 Go 结构体自动映射。

- `database/sql`：标准库，原生 SQL 操作

  - **手写 SQL**，直接执行查询，提高性能和灵活性。

    **需要手动扫描查询结果 (`rows.Scan()`)**。

    **手动管理事务、连接池**。

- `GORM`：ORM（对象关系映射），更高级的数据库操作

  - **更简单的 CURD 操作**，避免手写 SQL 语句。无需 `SELECT` 语句，直接 `db.Find(&users)`。

    **数据库迁移**，可以自动创建/更新表结构。

    **高级功能**：软删除、钩子（钩子函数）、关联查询。

    **对象映射**：不需要写 `CREATE TABLE`，只需要定义 `struct`，GORM 会自动创建表。

    **自动管理事务**。



## 原生 sql 标准库

Go 语言中的 `database/sql` 是一个标准库，提供了与关系型数据库交互的统一接口。它支持多种数据库（如 MySQL、PostgreSQL、SQLite 等），并简化了数据库连接、查询、事务管理等操作。

- **统一接口**：`database/sql` 提供了一个通用的 API，开发者可以使用相同的代码操作不同的数据库。
- **连接池管理**：自动管理数据库连接池，优化资源利用和性能。
- **事务支持**：支持事务操作，确保数据的一致性和完整性。
- **SQL 查询与执行**：支持执行 SQL 语句（如 `SELECT`、`INSERT`、`UPDATE`、`DELETE`）并处理结果。

### 基本用法

#### 安装与导入

`database/sql` 是 Go 标准库的一部分，无需额外安装。但需要根据使用的数据库安装相应的驱动，例如 MySQL 驱动：

```go
import (
    "database/sql"
    _ "github.com/go-sql-driver/mysql" // 匿名导入驱动
)
```

#### 连接数据库

使用 `sql.Open` 连接数据库：

```go
dsn := "user:password@tcp(127.0.0.1:3306)/dbname"
db, err := sql.Open("mysql", dsn)
if err != nil {
    log.Fatal(err)
}
defer db.Close() // 确保关闭连接
```

#### 执行 SQL 查询

使用 `QueryRow` 即可执行查询

- 查询单行数据：

  ```go
  var name string
  var age int
  err := db.QueryRow("SELECT name, age FROM users WHERE id = ? AND active = ?", 1, true).Scan(&name, &age)
  if err != nil {
      log.Fatal(err)
  }
  fmt.Println("Name:", name, "Age:", age)
  ```

  - 参数顺序：SQL 查询中的每个 `?` 都会按顺序被传递的参数替换。例如，第一个 `?` 被 `1` 替换，第二个 `?` 被 `true` 替换。
  - 结果扫描：`Scan` 方法中的变量顺序必须与查询结果中的列顺序一致。例如，`SELECT name, age` 的结果需要先扫描到 `name`，再扫描到 `age`。
  - 错误处理：如果查询失败（如没有匹配的行），`err` 会返回 `sql.ErrNoRows`，需要处理这种错误。

- 查询多行数据：

  ```go
  rows, err := db.Query("SELECT id, name FROM users")
  if err != nil {
      log.Fatal(err)
  }
  defer rows.Close()
  for rows.Next() {
      var id int
      var name string
      if err := rows.Scan(&id, &name); err != nil {
          log.Fatal(err)
      }
      fmt.Println(id, name)
  }
  ```

#### 执行 SQL 操作

- 插入数据：

  ```go
  result, err := db.Exec("INSERT INTO users (name, age) VALUES (?, ?)", "Alice", 25)
  if err != nil {
      log.Fatal(err)
  }
  id, _ := result.LastInsertId()
  fmt.Println("Inserted ID:", id)
  ```

- 更新数据：

  ```go
  _, err := db.Exec("UPDATE users SET age = ? WHERE id = ?", 26, 1)
  if err != nil {
      log.Fatal(err)
  }
  ```

- 删除数据：

  ```go
  _, err := db.Exec("DELETE FROM users WHERE id = ?", 1)
  if err != nil {
      log.Fatal(err)
  }
  ```

#### 事务管理

使用事务确保多个操作的原子性：

```go
tx, err := db.Begin()
if err != nil {
    log.Fatal(err)
}
defer tx.Rollback() // 回滚事务

_, err = tx.Exec("UPDATE account SET balance = balance - 100 WHERE id = 1")
if err != nil {
    log.Fatal(err)
}

_, err = tx.Exec("UPDATE account SET balance = balance + 100 WHERE id = 2")
if err != nil {
    log.Fatal(err)
}

err = tx.Commit() // 提交事务
if err != nil {
    log.Fatal(err)
}
```

### 高级功能

- 连接池配置：

  ```go
  db.SetMaxOpenConns(10) // 最大打开连接数
  db.SetMaxIdleConns(5)  // 最大闲置连接数
  db.SetConnMaxLifetime(time.Hour) // 连接最大生命周期
  ```

- 预处理语句，防止 SQL 注入：

  ```go
  stmt, err := db.Prepare("SELECT name FROM users WHERE age = ?")
  if err != nil {
      log.Fatal(err)
  }
  defer stmt.Close()
  rows, err := stmt.Query(25)
  ```

- 处理 NULL 值，使用`sql.NullString`等类型：

  ```go
  var name sql.NullString
  err := db.QueryRow("SELECT name FROM users WHERE id = ?", 1).Scan(&name)
  if name.Valid {
      fmt.Println("Name:", name.String)
  }
  ```



## GORM 使用基础步骤

1. 通过以下命令安装：

   ```bash
   go get -u gorm.io/gorm         # 核心库
   go get -u gorm.io/driver/mysql  # MySQL 驱动
   ```

2. 引入 gorm ：

   ```go
   import (
       "fmt"
       "gorm.io/gorm"
       "gorm.io/driver/mysql"
   )

3. 使用原生 sql 标准库创建数据库

   ```go
   var DB *gorm.DB
   
   func init() {
       // 1. 连接 MySQL（不指定数据库）
       username := "root"        // 账号
       password := "86503358299" // 密码
       host := "127.0.0.1"       // 数据库地址，可以是Ip或者域名
       port := 3306              // 故据库端口
       timeout := "10s"          // 连接超时，10秒
       dbname := "gorm"          // 数据库使用的表名
   
       // 类似格式：root:86503358299@tcp(127.0.0.1:3306)/gorm?
       dsnWithoutDB := fmt.Sprintf("%s:%s@tcp(%s:%d)/?charset=utf8mb4&parseTime=True&loc=Local&timeout=%s", username, password, host, port, timeout)
       sqlDB, err := sql.Open("mysql", dsnWithoutDB)
       if err != nil {
           log.Fatal("数据库连接失败: ", err)
       }
       defer sqlDB.Close()
   
       // 2. 创建数据库（如果不存在）
       _, err = sqlDB.Exec("CREATE DATABASE IF NOT EXISTS " + dbname)
       if err != nil {
           log.Fatal("创建数据库失败: ", err)
       }
       fmt.Println("数据库已创建（或已存在）")
   
       //...
   }

4. Gorm 连接数据库中的表

   ```go
   var DB *gorm.DB
   
   func init() {
       // ...
   
       // 3. 连接 GORM
       dsn := fmt.Sprintf("%s:%s@tcp(%s:%d)/%s?charset=utf8mb4&parseTime=True&loc=Local&timeout=%s",
                          username, password, host, port, dbname, timeout)
       db, err := gorm.Open(mysql.Open(dsn), &gorm.Config{
           // SkipDefaultTransaction : true // 跳过默认事务
       })
       if err != nil {
           panic("mysql 连接失败" + err.Error())
       }
       DB = db
   }
   ```

5. 设置表结构，并用 Gorm 自动迁移

   ```go
   // 数据库中表的结构
   type User struct {
       gorm.Model        // 内嵌字段（含ID、创建时间等）
       Name       string `gorm:"size:100"`   // 用户名，长度限制100
       Age        int    `gorm:"default:18"` // 年龄，默认值18
       Email      string `gorm:"unique"`     // 邮箱，唯一约束
   }
   
   // TableName 指定表名为 "gorm_users"
   func (User) TableName() string {
       return "gorm_users"
   }
   
   func main() {
       DB.AutoMigrate(&User{}) // 自动创建对应结构的表
       defer closeDB()
   }
   ```

6. 避免内存溢出，使用关闭数据库连接的函数

   ```go
   // 关闭数据库连接
   func closeDB() {
       sqlDB, err := DB.DB() // 获取底层 sql.DB 连接
       if err != nil {
           log.Fatal("获取数据库连接失败: ", err)
       }
       err = sqlDB.Close()
       if err != nil {
           log.Fatal("关闭数据库失败: ", err)
       }
       fmt.Println("数据库连接已关闭")
   }

完整示例：

```go
package main

import (
	"database/sql"
	"fmt"
	"gorm.io/driver/mysql"
	"gorm.io/gorm"
	"log"
)

var DB *gorm.DB

func init() {
	// 1. 连接 MySQL（不指定数据库）
	username := "root"        // 账号
	password := "86503358299" // 密码
	host := "127.0.0.1"       // 数据库地址，可以是Ip或者域名
	port := 3306              // 故据库端口
	timeout := "10s"          // 连接超时，10秒
	dbname := "gorm"          // 数据库名

	// 类似格式：root:86503358299@tcp(127.0.0.1:3306)/gorm?
	dsnWithoutDB := fmt.Sprintf("%s:%s@tcp(%s:%d)/?charset=utf8mb4&parseTime=True&loc=Local&timeout=%s", username, password, host, port, timeout)
	sqlDB, err := sql.Open("mysql", dsnWithoutDB)
	if err != nil {
		log.Fatal("数据库连接失败: ", err)
	}
	defer sqlDB.Close()

	// 2. 创建数据库（如果不存在）
	_, err = sqlDB.Exec("CREATE DATABASE IF NOT EXISTS " + dbname)
	if err != nil {
		log.Fatal("创建数据库失败: ", err)
	}
	fmt.Println("数据库已创建（或已存在）")

	// 3. 连接 GORM
	dsn := fmt.Sprintf("%s:%s@tcp(%s:%d)/%s?charset=utf8mb4&parseTime=True&loc=Local&timeout=%s",
		username, password, host, port, dbname, timeout)
	db, err := gorm.Open(mysql.Open(dsn), &gorm.Config{
		// SkipDefaultTransaction : true // 跳过默认事务
	})
	if err != nil {
		panic("mysql 连接失败" + err.Error())
	}
	DB = db
}

// 关闭数据库连接
func closeDB() {
	sqlDB, err := DB.DB() // 获取底层 sql.DB 连接
	if err != nil {
		log.Fatal("获取数据库连接失败: ", err)
	}
	err = sqlDB.Close()
	if err != nil {
		log.Fatal("关闭数据库失败: ", err)
	}
	fmt.Println("数据库连接已关闭")
}

// 数据库结构
type User struct {
	gorm.Model        // 内嵌字段（含ID、创建时间等）
	Name       string `gorm:"size:100"`   // 用户名，长度限制100
	Age        int    `gorm:"default:18"` // 年龄，默认值18
	Email      string `gorm:"unique"`     // 邮箱，唯一约束
}

// TableName 指定表名为 "gorm_users"
func (User) TableName() string {
	return "gorm_users"
}

func main() {
	DB.AutoMigrate(&User{}) // 自动创建对应结构的表
    defer closeDB()
}
```
