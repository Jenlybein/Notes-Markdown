# Gorm 模型定义

**Gorm Model Definition**

---

## 基本定义

GORM 通过将 Go 结构体（Go structs） 映射到数据库表来简化数据库交互。 了解如何在GORM中定义模型，是充分利用GORM全部功能的基础。

模型是使用普通结构体定义的。 这些结构体可以包含具有基本Go类型、指针或这些类型的别名，甚至是自定义类型（只需要实现 `database/sql` 包中的`Scanner`和`Valuer`接口）。

### 结构体映射规则

#### 命名约定

在GORM中，推荐以 `Model` 结尾命名结构体（如`UserModel`），以明确表示该结构体是数据库模型。这种命名方式有助于提高代码的可读性和一致性。

#### 字段标签

GORM通过字段标签（Tags）来定义结构体字段与数据库字段之间的映射规则。以下是一些常用的标签及其作用：

更多详细标签请参考官方文档：[模型定义 - 字段标签 | GORM.](https://gorm.io/zh_CN/docs/models.html#字段标签)

> 示例结构
>
> ```go
> type UserModel struct {
>     ID        int64     `gorm:"primaryKey;autoIncrement"` // 主键且自增
>     Name      string    `gorm:"not null;unique;size:128"` // 非空唯一+长度限制
> }
> ```
>
> - `primaryKey`：声明主键（复合主键用逗号分隔）
> - `not null`：字段不可为空，插入空值会触发错误
> - `unique`：建立唯一索引，防止重复数据
> - `size`：控制字段长度（如`varchar(128)`）

#### 模型结构约定

1. **主键**：GORM默认使用名为 `ID` 的字段作为主键。如果字段类型为 `int`，GORM会自动将其设置为自增主键。
2. **表名**：默认情况下，GORM将结构体名称转换为 `snake_case` 并为表名加上复数形式。例如，`User` 结构体对应的表名为 `users`。
3. **列名**：GORM自动将结构体字段名称转换为 `snake_case` 作为数据库中的列名。例如，`CreatedAt` 字段对应的列名为 `created_at`。
4. **时间戳字段**：GORM使用 `CreatedAt` 和 `UpdatedAt` 字段来自动跟踪记录的创建和更新时间。
5. **普通类型**：普通类型，如 `uint`、`string` 和 `uint8`等可直接使用。
6. **可空字段**：使用指向 `*string` 和 `*time.Time` 类型的指针表示可空字段。
7. **更复杂的可空字段**：使用 `database/sql` 包中的 `sql.NullString` 和 `sql.NullTime` 来处理具有更多控制的可空字段。

### 预定义的结构体

GORM提供了一个预定义的结构体，名为`gorm.Model`，其中包含常用字段：

```go
// gorm.Model 的定义
type Model struct {
  ID        uint           `gorm:"primaryKey"`
  CreatedAt time.Time
  UpdatedAt time.Time
  DeletedAt gorm.DeletedAt `gorm:"index"`
}
```

- **将其嵌入在您的结构体中**: 您可以直接在您的结构体中嵌入 `gorm.Model` ，以便自动包含这些字段。 这对于在不同模型之间保持一致性并利用GORM内置的约定非常有用。
- **包含的字段**：
  - `ID` ：每个记录的唯一标识符（主键）。
  - `CreatedAt` ：在创建记录时自动设置为当前时间。
  - `UpdatedAt`：每当记录更新时，自动更新为当前时间。
  - `DeletedAt`：用于软删除（将记录标记为已删除，而实际上并未从数据库中删除）。



## 高级选项

### 字段级权限控制

可导出的字段在使用 GORM 进行 CRUD 时拥有全部的权限。

此外，GORM 允许用标签控制字段级别的权限。这就可让一个字段的权限是只读、只写、只创建、只更新或者被忽略。

> **注意：** 使用 GORM Migrator 创建表时，不会创建被忽略的字段

```go
type User struct {
    Name string `gorm:"<-:create"`          // 允许读和创建
    Name string `gorm:"<-:update"`          // 允许读和更新
    Name string `gorm:"<-"`                 // 允许读和写（创建和更新）
    Name string `gorm:"<-:false"`           // 允许读，禁止写
    Name string `gorm:"->"`                 // 只读（除非有自定义配置，否则禁止写）
    Name string `gorm:"->;<-:create"`       // 允许读和写
    Name string `gorm:"->:false;<-:create"` // 仅创建（禁止从 db 读）
    Name string `gorm:"-"`                  // 通过 struct 读写会忽略该字段
    Name string `gorm:"-:all"`              // 通过 struct 读写、迁移会忽略该字段
    Name string `gorm:"-:migration"`        // 通过 struct 迁移会忽略该字段
}
```

### 时间字段自动化

GORM提供了内置的时间追踪功能，方便开发者自动管理记录的创建、更新和删除时间。

- **内置时间追踪**：

  - `CreatedAt`：在首次保存记录时，GORM会自动将当前时间赋值给该字段。
  - `UpdatedAt`：每次更新记录时，GORM会自动刷新该字段为当前时间。
  - `DeletedAt`：启用软删除时，GORM会自动将当前时间赋值给该字段。

  ```go
  type UserModel struct {
      CreatedAt time.Time	// 自动记录创建时间
      UpdatedAt time.Time	// 自动记录更新时间
  }
  ```

- **自定义时间字段名**：
  如果不想使用默认的 `CreatedAt` 和 `UpdatedAt` 字段名，可以通过 `autoCreateTime` 和 `autoUpdateTime` 标签来自定义字段名。例如：

  ```go
  type UserModel struct {
    CreateTime time.Time `gorm:"autoCreateTime"` // 自定义创建时间字段
    ModifyTime time.Time `gorm:"autoUpdateTime"` // 自定义更新时间字段
  }
  ```

### 嵌入结构体

在GORM中，嵌入结构体是一种将字段和方法从子结构体提升到父结构体的机制，能够显著简化代码并增强可复用性。以下是关于嵌入结构体的详细说明：

#### 匿名字段嵌入

通过匿名字段，GORM会自动将子结构体的字段包含在父结构体中。例如：

```go
type Author struct {
  Name  string
  Email string
}

type Blog struct {
  Author
  ID      int
  Upvotes int32
}
```

上述代码等效于：

```go
type Blog struct {
  ID      int64
  Name    string
  Email   string
  Upvotes int32
}
```

#### 显式嵌入

对于非匿名字段，可以通过`embedded`标签显式嵌入子结构体。例如：

```go
type Author struct {
    Name  string
    Email string
}

type Blog struct {
  ID      int
  Author  Author `gorm:"embedded"`
  Upvotes int32
}
```

上述代码等效于：

```go
type Blog struct {
  ID    int64
  Name  string
  Email string
  Upvotes  int32
}
```

#### 字段前缀

通过`embeddedPrefix`标签，可以为嵌入字段的数据库列名添加前缀。例如：

```go
type Blog struct {
  ID      int
  Author  Author `gorm:"embedded;embeddedPrefix:author_"`
  Upvotes int32
}
```

上述代码等效于：

```go
type Blog struct {
  ID          int64
  AuthorName  string
  AuthorEmail string
  Upvotes     int32
}
```

> 将 Grom 预定义的结构体`gorm.Model`嵌入，则可以节省代码空间，
>
> ```go
> // 数据库结构
> type User struct {
> 	gorm.Model        // 内嵌字段（含ID、创建时间等）
> 	Name       string `gorm:"size:100"`   // 用户名，长度限制100
> 	Age        int    `gorm:"default:18"` // 年龄，默认值18
> 	Email      string `gorm:"unique"`     // 邮箱，唯一约束
> }
