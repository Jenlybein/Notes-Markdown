# GORM 查询

**Gorm Search**

---

## 检索单个对象

GORM 提供了 `First`、`Take`、`Last` 方法来查询单个对象。这些方法会自动添加 `LIMIT 1` 条件，如果没有找到记录，会返回 `ErrRecordNotFound` 错误。

```go
// 获取第一条记录（主键升序）
db.First(&user)
// SELECT * FROM users ORDER BY id LIMIT 1;

// 获取一条记录，没有指定排序字段
db.Take(&user)
// SELECT * FROM users LIMIT 1;

// 获取最后一条记录（主键降序）
db.Last(&user)
// SELECT * FROM users ORDER BY id DESC LIMIT 1;

// 传入切片用作存储数据，通过 db.Model() 指定了模型
result := map[string]interface{}{}
db.Model(&User{}).First(&result)
// SELECT * FROM users ORDER BY id LIMIT 1;
```

`First` and `Last` 方法分别会按**主键**排序找到第一条记录和最后一条记录，所以需要知道表结构才能运作。 只有在目标 struct 是指针或者通过 `db.Model()` 指定 model 时，该方法才有效。 

- `Model` 方法用于指定查询的表或模型，`db.Model(&User{})` 表示指定 `User` 模型。
- `db.Table("users")` 是 GORM 中用于直接操作数据库表的方法。它允许你绕过模型（Model）直接对指定的表进行查询操作。

```go
// 无效，因为没有指定模型，只是指定了表名，GORM 无法确定排序字段
result := map[string]interface{}{}
db.Table("users").First(&result);

// 有效，使用 Take 方法，不依赖排序，直接获取一条记录
result := map[string]interface{}{}
db.Table("users").Take(&result);
```

此外，如果相关 model 没有定义主键，那么将按 model 的第一个字段进行排序。

```go
// 未定义主键，按第一个字段排序
type Language struct {
  Code string
  Name string
}
db.First(&Language{})
// SELECT * FROM languages ORDER BY code LIMIT 1;
```

 **检查错误**：

```go
result := db.First(&user)
result.RowsAffected // 返回找到的记录数
result.Error        // 返回 error 或 nil
if errors.Is(result.Error, gorm.ErrRecordNotFound) {
    fmt.Println("记录未找到")
}
```

如果想避免 `ErrRecordNotFound` 错误，可以使用 `Find` 方法，并添加 `LIMIT 1` 条件：

```go
db.Limit(1).Find(&user)
```

- `Find`方法可以接受struct和slice的数据。
- 对单个对象使用`Find`而不带limit，`db.Find(&user)`将会查询整个表并且只返回第一个对象，只是性能不高并且不确定的。

#### 根据主键检索

如果主键是数字类型，可以直接使用内联条件查询：

```go
db.First(&user, 10)
// SELECT * FROM users WHERE id = 10;

db.First(&user, "10")
// SELECT * FROM users WHERE id = 10;

db.Find(&users, []int{1,2,3})
// SELECT * FROM users WHERE id IN (1,2,3);
```

如果主键是字符串类型（如 UUID），可以这样查询：

```go
db.First(&user, "id = ?", "1b74413f-f3b8-409f-ac47-e8c062e3472a")
// SELECT * FROM users WHERE id = "1b74413f-f3b8-409f-ac47-e8c062e3472a";
```

当目标对象有一个主键值时，将使用主键构建查询条件，例如：

```go
var user = User{ID: 10}
db.First(&user)
// SELECT * FROM users WHERE id = 10;

var result User
db.Model(User{ID: 10}).First(&result)
// SELECT * FROM users WHERE id = 10;
```

> **NOTE:** 如果您使用 gorm 的特定字段类型（例如 `gorm.DeletedAt`），它将运行不同的查询来检索对象。
>
> ```
> type User struct {
>   ID           string `gorm:"primarykey;size:16"`
>   Name         string `gorm:"size:24"`
>   DeletedAt    gorm.DeletedAt `gorm:"index"`
> }
> 
> var user = User{ID: 15}
> db.First(&user)
> //  SELECT * FROM `users` WHERE `users`.`id` = '15' AND `users`.`deleted_at` IS NULL ORDER BY `users`.`id` LIMIT 1
> ```

## 检索全部对象

使用 `Find` 方法可以检索所有记录：

```go
db.Find(&users)
// SELECT * FROM users;

result.RowsAffected // 返回找到的记录数, equals `len(users)`
result.Error        // 返回 error 或 nil
```

## 条件查询

你可以使用 `Where` 方法添加查询条件：

```go
// 获取第一条匹配的记录
db.Where("name = ?", "jinzhu").First(&user)
// SELECT * FROM users WHERE name = 'jinzhu' ORDER BY id LIMIT 1;

// 获取所有 name 不等于 "jinzhu" 匹配的记录
db.Where("name <> ?", "jinzhu").Find(&users)
// SELECT * FROM users WHERE name <> 'jinzhu';

// IN 条件
db.Where("name IN ?", []string{"jinzhu", "jinzhu 2"}).Find(&users)
// SELECT * FROM users WHERE name IN ('jinzhu', 'jinzhu 2');

// LIKE 条件
db.Where("name LIKE ?", "%jin%").Find(&users)
// SELECT * FROM users WHERE name LIKE '%jin%';

// AND 条件
db.Where("name = ? AND age >= ?", "jinzhu", "22").Find(&users)
// SELECT * FROM users WHERE name = 'jinzhu' AND age >= 22;

// 时间条件
db.Where("updated_at > ?", lastWeek).Find(&users)
// SELECT * FROM users WHERE updated_at > '2000-01-01 00:00:00';

// BETWEEN 条件
db.Where("created_at BETWEEN ? AND ?", lastWeek, today).Find(&users)
// SELECT * FROM users WHERE created_at BETWEEN '2000-01-01 00:00:00' AND '2000-01-08 00:00:00';
```

> 如果对象设置了主键，条件查询将不会覆盖主键的值，而是用 And 连接条件。 例如：
>
> ```go
> var user = User{ID: 10}
> db.Where("id = ?", 20).First(&user)
> // SELECT * FROM users WHERE id = 10 and id = 20 ORDER BY id ASC LIMIT 1
> ```
>
> 这个查询将会给出`record not found`错误 所以，在你想要使用例如 `user` 这样的变量从数据库中获取新值前，需要将例如 `id` 这样的主键设置为nil。

### 使用结构体或 Map 条件

你可以使用结构体或 Map 来指定查询条件：

```go
// 使用结构体
db.Where(&User{Name: "jinzhu", Age: 20}).First(&user)
// SELECT * FROM users WHERE name = "jinzhu" AND age = 20 ORDER BY id LIMIT 1;

// 使用 Map
db.Where(map[string]interface{}{"name": "jinzhu", "age": 20}).Find(&users)
// SELECT * FROM users WHERE name = "jinzhu" AND age = 20;

// Slice of primary keys
db.Where([]int64{20, 21, 22}).Find(&users)
// SELECT * FROM users WHERE id IN (20, 21, 22);
```

- 注意使用struct查询时，GORM只会查询非零字段，这意味着如果您的字段值为`0`、`"`、`false`或其他零值，则不会用于构建查询条件。

  ```go
  db.Where(&User{Name: "jinzhu", Age: 0}).Find(&users)
  // SELECT * FROM users WHERE name = "jinzhu";

- 要在查询条件中包含零值，您可以使用 `map`，该映射将包含所有键值作为查询条件。

  ```go
  db.Where(map[string]interface{}{"Name": "jinzhu", "Age": 0}).Find(&users)
  // SELECT * FROM users WHERE name = "jinzhu" AND age = 0;

### Not 条件

类似于 `Where`，NOT 会排除不符合的条件。

```go
db.Not("name = ?", "jinzhu").First(&user)
// SELECT * FROM users WHERE NOT name = "jinzhu" ORDER BY id LIMIT 1;

// Not In
db.Not(map[string]interface{}{"name": []string{"jinzhu", "jinzhu 2"}}).Find(&users)
// SELECT * FROM users WHERE name NOT IN ("jinzhu", "jinzhu 2");

// Struct
db.Not(User{Name: "jinzhu", Age: 18}).First(&user)
// SELECT * FROM users WHERE name <> "jinzhu" AND age <> 18 ORDER BY id LIMIT 1;

// Not In slice of primary keys
db.Not([]int64{1,2,3}).First(&user)
// SELECT * FROM users WHERE id NOT IN (1,2,3) ORDER BY id LIMIT 1;
```

### Or 条件

拼接 `Or` 

```go
db.Where("role = ?", "admin").Or("role = ?", "super_admin").Find(&users)
// SELECT * FROM users WHERE role = 'admin' OR role = 'super_admin';

// Struct
db.Where("name = 'jinzhu'").Or(User{Name: "jinzhu 2", Age: 18}).Find(&users)
// SELECT * FROM users WHERE name = 'jinzhu' OR (name = 'jinzhu 2' AND age = 18);

// Map
db.Where("name = 'jinzhu'").Or(map[string]interface{}{"name": "jinzhu 2", "age": 18}).Find(&users)
// SELECT * FROM users WHERE name = 'jinzhu' OR (name = 'jinzhu 2' AND age = 18);
```

### 排序和分页

你可以使用 `Order`、`Limit` 和 `Offset` 方法来排序和分页：

```go
// 按年龄降序排序
db.Order("age desc").Find(&users)
// SELECT * FROM users ORDER BY age desc;

// 分页查询
db.Limit(10).Offset(5).Find(&users)
// SELECT * FROM users LIMIT 10 OFFSET 5;
```

### Group By & Having

```go
type result struct {
  Date  time.Time
  Total int
}

// 查询 name 以 "group" 开头的用户，按 name 分组并计算 age 的总和，返回第一条记录
db.Model(&User{}).Select("name, sum(age) as total").Where("name LIKE ?", "group%").Group("name").First(&result)
// 生成的 SQL: SELECT name, sum(age) as total FROM `users` WHERE name LIKE "group%" GROUP BY `name` LIMIT 1

// 按 name 分组并计算 age 的总和，筛选出 name 为 "group" 的记录
db.Model(&User{}).Select("name, sum(age) as total").Group("name").Having("name = ?", "group").Find(&result)
// 生成的 SQL: SELECT name, sum(age) as total FROM `users` GROUP BY `name` HAVING name = "group"
```

### 使用 Rows 遍历结果

```go
// 查询 orders 表，按 created_at 的日期分组并计算 amount 的总和
rows, err := db.Table("orders").Select("date(created_at) as date, sum(amount) as total").Group("date(created_at)").Rows()
defer rows.Close()
for rows.Next() {
  // 处理每一行数据
}

// 查询 orders 表，按 created_at 的日期分组并计算 amount 的总和，筛选出总和大于 100 的记录
rows, err := db.Table("orders").Select("date(created_at) as date, sum(amount) as total").Group("date(created_at)").Having("sum(amount) > ?", 100).Rows()
defer rows.Close()
for rows.Next() {
  // 处理每一行数据
}
```

### 使用 Scan 将结果映射到结构体

```go
type Result struct {
  Date  time.Time
  Total int64
}

// 查询 orders 表，按 created_at 的日期分组并计算 amount 的总和，筛选出总和大于 100 的记录，并将结果映射到 Result 结构体
db.Table("orders").Select("date(created_at) as date, sum(amount) as total").Group("date(created_at)").Having("sum(amount) > ?", 100).Scan(&results)

// 将查询结果映射到 Result 结构体
var result Result
db.Table("users").Select("name", "age").Where("name = ?", "Antonio").Scan(&result)

// 使用原生 SQL 查询
db.Raw("SELECT name, age FROM users WHERE name = ?", "Antonio").Scan(&result)
```

### Distinct

```go
// 查询 users 表中 name 和 age 的唯一组合，并按 name 升序、age 降序排序
db.Distinct("name", "age").Order("name, age desc").Find(&results)
// Distinct 也可以与 Pluck 和 Count 一起使用
```

### Joins

```go
type result struct {
  Name  string
  Email string
}

// 查询 users 表和 emails 表，使用左连接获取用户的 name 和 email
db.Model(&User{}).Select("users.name, emails.email").Joins("left join emails on emails.user_id = users.id").Scan(&result{})
// 生成的 SQL: SELECT users.name, emails.email FROM `users` left join emails on emails.user_id = users.id

// 使用 Rows 遍历结果
rows, err := db.Table("users").Select("users.name, emails.email").Joins("left join emails on emails.user_id = users.id").Rows()
for rows.Next() {
  // 处理每一行数据
}

// 将结果映射到结构体
db.Table("users").Select("users.name, emails.email").Joins("left join emails on emails.user_id = users.id").Scan(&results)

// 多表连接，带参数
db.Joins("JOIN emails ON emails.user_id = users.id AND emails.email = ?", "jinzhu@example.org").Joins("JOIN credit_cards ON credit_cards.user_id = users.id").Where("credit_cards.number = ?", "411111111111").Find(&user)
```

### Joins 预加载

```go
// 预加载 Company 关联，使用左连接
db.Joins("Company").Find(&users)
// 生成的 SQL: SELECT `users`.`id`,`users`.`name`,`users`.`age`,`Company`.`id` AS `Company__id`,`Company`.`name` AS `Company__name` FROM `users` LEFT JOIN `companies` AS `Company` ON `users`.`company_id` = `Company`.`id`

// 使用内连接
db.InnerJoins("Company").Find(&users)
// 生成的 SQL: SELECT `users`.`id`,`users`.`name`,`users`.`age`,`Company`.`id` AS `Company__id`,`Company`.`name` AS `Company__name` FROM `users` INNER JOIN `companies` AS `Company` ON `users`.`company_id` = `Company`.`id`

// 带条件的连接
db.Joins("Company", db.Where(&Company{Alive: true})).Find(&users)
// 生成的 SQL: SELECT `users`.`id`,`users`.`name`,`users`.`age`,`Company`.`id` AS `Company__id`,`Company`.`name` AS `Company__name` FROM `users` LEFT JOIN `companies` AS `Company` ON `users`.`company_id` = `Company`.`id` AND `Company`.`alive` = true
```

### Joins 衍生表

```go
type User struct {
    Id  int
    Age int
}

type Order struct {
    UserId     int
    FinishedAt *time.Time
}

// 查询 order 表，按 user_id 分组并获取 finished_at 的最大值，筛选出 age 大于 18 的用户
query := db.Table("order").Select("MAX(order.finished_at) as latest").Joins("left join user user on order.user_id = user.id").Where("user.age > ?", 18).Group("order.user_id")
db.Model(&Order{}).Joins("join (?) q on order.finished_at = q.latest", query).Scan(&results)
// 生成的 SQL: SELECT `order`.`user_id`,`order`.`finished_at` FROM `order` join (SELECT MAX(order.finished_at) as latest FROM `order` left join user user on order.user_id = user.id WHERE user.age > 18 GROUP BY `order`.`user_id`) q on order.finished_at = q.latest
```

这段代码的作用是执行一个复杂的 SQL 查询，目的是从 `order` 表中获取每个用户的最新订单，并将结果映射到 `results` 中。

- **子查询部分**：指定查询的表为 `order`, 选择每个用户的最新订单完成时间（`finished_at`），并将其命名为 `latest`, 通过 `order.user_id` 和 `user.id` 进行左连接，关联 `order` 表和 `user` 表, 筛选出 `user` 表中年龄大于 18 的用户, 按 `order.user_id` 分组，确保每个用户只返回一条记录（即最新订单的完成时间）。
- **主查询部分**：
  - `db.Model(&Order{})`：指定查询的模型为 `Order`。
  - `Joins("join (?) q on order.finished_at = q.latest", query)`：将子查询 `query` 的结果作为一个临时表 `q`，并将其与 `order` 表进行连接，条件是 `order.finished_at` 等于 `q.latest`（即最新订单的完成时间）。
  - `Scan(&results)`：将查询结果映射到 `results` 中。
