# Grom 创建记录

**Grom Create**

---

## 创建

以下是对 GORM 创建记录的详细解析，涵盖单条记录、批量插入、字段选择、钩子函数等高级特性。表中示例结构体为：

```go
type User struct {
    gorm.Model           // 内嵌字段（含ID、创建时间等）
    Name       string    `gorm:"size:100"`   // 用户名，长度限制100
    Age        int       `gorm:"default:18"` // 年龄，默认值18
    Birthday   time.Time 					 // 生日
}
```

### 单条记录创建

创建单条记录是 GORM 中最基础的操作。通过 `Create` 方法，可以将结构体实例插入到数据库中。

```go
user := User{Name: "Jinzhu", Age: 18, Birthday: time.Now()}
result := db.Create(&user) // 必须传递指针

fmt.Println(user.ID)        // 返回插入数据的主键
fmt.Println(result.Error)   // 返回 error
fmt.Println(result.RowsAffected) // 返回插入记录的条数
```

- `Create` 方法必须接收结构体的指针（`&user`），否则会报错。
- 插入成功后，GORM 会自动回填主键值到 `user.ID`。

### 多条记录创建

批量插入是高效处理大量数据的常用方式。GORM 支持将切片传递给 `Create` 方法，一次性插入多条记录。

```go
users := []*User{
    {Name: "Jinzhu", Age: 18, Birthday: time.Now()},
    {Name: "Jackson", Age: 19, Birthday: time.Now()},
}

result := db.Create(users) // 插入多条记录

fmt.Println(result.Error)        // 返回 error
fmt.Println(result.RowsAffected) // 返回插入记录的条数
```

```go
var users = []User{{Name: "jinzhu1"}, {Name: "jinzhu2"}, {Name: "jinzhu3"}}
db.Create(&users)

for _, user := range users {
    user.ID // 1,2,3
}
```

- GORM 会生成一条 SQL 语句来插入所有数据，并回填主键值。
- 如果记录数量较大，GORM 会自动将数据分割成多个批次，并在事务中处理。

#### 分批插入

通过 `CreateInBatches` 方法，可以指定每批插入的记录数。

```go
var users = []User{{Name: "jinzhu_1"}, ..., {Name: "jinzhu_10000"}}
db.CreateInBatches(users, 100) // 每批插入 100 条记录
```

> **注意** 使用`CreateBatchSize` 选项初始化GORM实例后，此后进行创建& 关联操作时所有的`INSERT`行为都会遵循初始化时的配置。
>
> ```go
> 
> db, err := gorm.Open(mysql.Open(dsn), &gorm.Config{
>     CreateBatchSize: 1000,
> })
> 
> db := db.Session(&gorm.Session{CreateBatchSize: 1000})
> 
> users = [5000]User{{Name: "jinzhu", Pets: []Pet{pet1, pet2, pet3}}...}
> 
> db.Create(&users)
> // INSERT INTO users xxx (5 batches)
> // INSERT INTO pets xxx (15 batches)
> ```

### 字段选择与忽略

在某些场景下，可能需要只插入部分字段或忽略某些字段。GORM 提供了 `Select` 和 `Omit` 方法来实现这一需求。

- **选择字段**：使用 `Select` 方法指定需要插入的字段。

```go
db.Select("Name", "Age", "CreatedAt").Create(&user)
// SQL: INSERT INTO `users` (`name`,`age`,`created_at`) VALUES ("jinzhu", 18, "2020-07-04 11:05:21.775")
```

- **忽略字段**：使用 `Omit` 方法忽略某些字段。

```go
db.Omit("Name", "Age", "CreatedAt").Create(&user)
// SQL: INSERT INTO `users` (`birthday`,`updated_at`) VALUES ("2020-01-01 00:00:00.000", "2020-07-04 11:05:21.775")
```

### 创建钩子

GORM 支持在创建记录时触发钩子方法，允许开发者在插入前后执行自定义逻辑。

```go
// BeforeCreate 是 GORM 的钩子函数，在创建记录之前自动调用
func (u *User) BeforeCreate(tx *gorm.DB) (err error) {
    fmt.Println("创建的钩子函数")
    u.UUID = uuid.New() // 为 User 生成一个唯一的 UUID

    // 检查用户角色是否为 "admin"，如果是，返回错误
    if u.Role == "admin" {
        return errors.New("invalid role")
    }

    return // 如果没有错误，返回 nil
}
```

- **钩子类型**：
  - `BeforeSave`：在保存前触发。
  - `BeforeCreate`：在创建前触发。
  - `AfterSave`：在保存后触发。
  - `AfterCreate`：在创建后触发。
- **跳过钩子**：
  通过 `SkipHooks` 会话模式，可以跳过钩子函数的执行。

```go
db.Session(&gorm.Session{SkipHooks: true}).Create(&user)
DB.Session(&gorm.Session{SkipHooks: true}).Create(&users)
DB.Session(&gorm.Session{SkipHooks: true}).CreateInBatches(users, 100)
```

#### 根据 Map 创建

GORM 支持通过 `map[string]interface{}` 与 `[]map[string]interface{}{}`创建记录，适用于动态字段的场景。

```go
db.Model(&User{}).Create(map[string]interface{}{
    "Name": "jinzhu", 
    "Age": 18,
})

// batch insert from `[]map[string]interface{}{}`
db.Model(&User{}).Create([]map[string]interface{}{
    {"Name": "jinzhu_1", "Age": 18},
    {"Name": "jinzhu_2", "Age": 20},
})
```

- 注意事项：使用 `map` 创建时，钩子函数不会执行，关联不会被保存，且不会回填主键。

### 使用 SQL 表达式

GORM 允许使用 SQL 表达式`clause.Expr`插入数据，适用于需要动态生成字段值的场景。

1. **使用 `map[string]interface{}`**

   通过 `map`，你可以直接指定字段的值，并使用 SQL 表达式动态生成某些字段的值。

   ```go
   // 假设有一个表结构记录用户的地理坐标
   type User struct {
       gorm.Model
       Name      string    `gorm:"not null"`
       Location  string    `gorm:"type:geometry"`
   }
   
   db.Model(User{}).Create(map[string]interface{}{
       "Name": "jinzhu",
       "Location": clause.Expr{
           SQL:  "ST_PointFromText(?)", // SQL 表达式
           Vars: []interface{}{"POINT(100 100)"}, // 表达式参数
       },
   })
   ```

   - `Name` 字段直接赋值 `"jinzhu"`。

   - `Location` 字段使用 SQL 表达式 `ST_PointFromText`，并传入参数 `"POINT(100 100)"`。

   - 最终生成的 SQL 语句是：

     ```sql
     INSERT INTO `users` (`name`,`location`) VALUES ("jinzhu",ST_PointFromText("POINT(100 100)"));
     ```

2. **使用自定义数据类型**

   通过自定义数据类型，你可以将复杂的 SQL 表达式封装到结构体中，使代码更清晰。

   ```go
   type Location struct {
       X, Y int
   }
   
   // 实现 GormValue 方法，返回 SQL 表达式
   func (loc Location) GormValue(ctx context.Context, db *gorm.DB) clause.Expr {
       return clause.Expr{
           SQL:  "ST_PointFromText(?)",
           Vars: []interface{}{fmt.Sprintf("POINT(%d %d)", loc.X, loc.Y)},
       }
   }
   
   type User struct {
       Name     string
       Location Location
   }
   
   // 创建记录
   db.Create(&User{
       Name:     "jinzhu",
       Location: Location{X: 100, Y: 100},
   })
   ```

   - `Location` 结构体表示一个地理坐标。

   - `GormValue` 方法定义了如何将 `Location` 转换为 SQL 表达式。

   - 最终生成的 SQL 语句是：

     ```sql
     INSERT INTO `users` (`name`,`location`) VALUES ("jinzhu",ST_PointFromText("POINT(100 100)"));
     ```

### 关联创建

GORM 支持在创建记录时自动处理关联数据。在 GORM 中，**关联创建**是指在创建一条记录时，同时创建或更新与其关联的其他记录。

```go
type CreditCard struct {
    gorm.Model
    Number string
    UserID uint
}

type User struct {
    gorm.Model
    Name       string
    CreditCard CreditCard
}

db.Create(&User{
    Name: "jinzhu",
    CreditCard: CreditCard{Number: "411111111111"},
})
```

- `User` 和 `CreditCard` 是两个关联的模型，`User` 拥有一个 `CreditCard`（一对一关系）。

- 当创建 `User` 时，GORM 会自动创建 `CreditCard` 记录，并将它们关联起来。

- 生成的 SQL 语句如下：

  ```sql
  INSERT INTO `users` (`name`) VALUES ("jinzhu");
  INSERT INTO `credit_cards` (`number`, `user_id`) VALUES ("411111111111", 1);
  ```

- **跳过关联**：通过 `Omit` 方法可以跳过关联的更新。

### 默认值

#### 基本用法

通过 `default` Tag，可以为字段设置默认值。例如：

```go
type User struct {
    ID   int64
    Name string `gorm:"default:galeone"` // Name 的默认值为 "galeone"
    Age  int64  `gorm:"default:18"`     // Age 的默认值为 18
}
```

- 当创建记录时，如果字段值为零值（如 `""`、`0`、`false`），GORM 会使用 `default` Tag 指定的默认值插入数据库。

#### 处理零值

如果字段的零值（如 `0`、`""`、`false`）需要保存到数据库，可以使用指针类型或 `Scanner/Valuer` 接口：

```go
type User struct {
    gorm.Model
    Name   string
    Age    *int           `gorm:"default:18"` // 使用指针类型
    Active sql.NullBool   `gorm:"default:true"` // 使用 sql.NullBool
}
```

- 指针类型或 `Scanner/Valuer` 接口可以区分零值和未赋值的情况。

#### 跳过默认值

如果不想在数据库迁移时使用默认值，可以使用 `default:(-)`：

```go
type User struct {
    ID        string `gorm:"default:uuid_generate_v3()"` // 使用数据库函数生成默认值
    FirstName string
    LastName  string
    Age       uint8
    FullName  string `gorm:"->;type:GENERATED ALWAYS AS (concat(firstname,' ',lastname));default:(-);"` // 跳过默认值
}
```
